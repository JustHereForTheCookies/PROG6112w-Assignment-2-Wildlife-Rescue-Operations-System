## Description

This is a console-based Java application for WildLife SA, a non-profit conservation organisation. The system manages wildlife rescue cases, including 
injured animal rescues,	 orphaned animal rescues, 	and endangered species rescues.

The application stores rescue cases in an `ArrayList`, calculates total rescue costs, determines rescue priority, updates rescue status, and generates reports.

## Features

- Create Injured Animal Rescue
- Create Orphaned Animal Rescue
- Create Endangered Species Rescue
- Search rescue case by ID
- Update rescue status
- Start rescue operation
- Complete rescue operation
- Generate rescue summary
- Generate rescue report with totals
